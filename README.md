# Where the Greeks Fought

An interactive map, the win–draw–loss records and the full list of the 713 recorded land and sea battles of the Greek city-states and kingdoms,
from the first battles known from the sources (c. 700 BCE) to the last Greek kingdoms (14 BCE).

**Open the page:** https://iosiflazaridis.github.io/ancient-greek-battles/

- `index.html`: the page (self-contained; the data are embedded)
- `img/`: the nine images in full size (3200 × 1800); `thumb/`: their thumbnails
- `dl/`: the data as CSV, JSON and an Excel workbook (with the win–draw–loss table)

Sources: the ancient authors, cited battle by battle in the data. Map: Natural Earth.
